# 🔑 Password Strength Checker (Python)

A simple Python script to evaluate the strength of a password based on multiple criteria.  
This tool helps users create secure passwords by checking for **length, uppercase, lowercase, digits, and special characters**.

---

## ✨ Features
- ✅ Minimum length check (8 characters)  
- ✅ Uppercase, lowercase, digit, and special character validation  
- ✅ Feedback on missing elements  
- ✅ Categorizes password as **Weak ❌**, **Moderate ⚠️**, or **Strong ✅**
